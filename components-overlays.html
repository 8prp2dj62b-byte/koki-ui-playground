Temporary Context
KOKI / Components / Principles
Temporary context · derived from frozen overlap

Overlay only when context must temporarily move above the task.

KOKI не използва floating surfaces като декорация. Menu и Popover са Floating context. Sheet и Dialog са Modal context, когато блокират основната задача. Всеки overlay трябва да има ясна причина да съществува над съдържанието и ясен начин да приключи.

Candidate 0.1 · no mockup inheritance
Floating

Menu, popover, compact contextual action. Solid Surface + frozen floating shadow. Без scrim.

Modal

Dialog или blocking sheet. Solid Surface + frozen modal shadow + neutral scrim.

Never

Static cards with shadow, glass content, nested modals или overlay само за визуална тежест.

Decision rule

Can it stay inline?Ако да, не използвай overlay.
Needs anchor?Кратък contextual choice → Menu/Popover.
Needs isolation?Решение, което временно спира основната задача → Dialog/Sheet.

Floating · Menu

A menu chooses an action, not a destination hierarchy.

Menu е кратък списък от contextual actions, anchored към конкретен trigger. Използва текст по подразбиране; icon се добавя само ако ускорява разпознаването.

Mercedes Roof Box

Menu е свързано с конкретния object context и не променя основната navigation hierarchy.

Destructive action stays explicit
WidthОпределя се от съдържанието и наличното пространство; не се превръща в mini panel.
RowsМинимум 44px interactive target; 52px при supporting text.
CloseSelection, outside click, Escape или загуба на валиден anchor.
Floating · Popover

A popover explains or resolves a compact local question.

Popover може да носи кратко explanation, preview или малък decision set. Ако съдържанието стане дълго, многостъпково или critical, то вече не е popover.

Целева цена

Потребителят иска кратко обяснение на стойността, без да напуска текущия context.

Modal · Mobile sheet

On mobile, temporary decisions belong near the thumb.

Sheet е preferred mobile expression за кратък modal task, когато desktop еквивалентът би бил dialog или larger popover. Не се използва като постоянен content container.

Mercedes Roof Box
Основният context остава отдолу и временно става недостъпен, докато потребителят завърши или затвори sheet-а.

Modal · Dialog

A dialog isolates one decision.

Dialog не е mini page. Заглавие, кратко consequence/context, само необходимото съдържание и ясни действия. Няма nested navigation.

Основна задача

Работният context остава видим само като фон и е временно недостъпен.

Modal · Destructive confirmation

Confirmation exists for consequence, not ceremony.

Не всяко действие получава confirmation. Използваме го, когато последицата е разрушителна, трудно обратима или променя ownership/control по значим начин.

Активна продажба

KOKI ще спре автоматичната работа по тази продажба. Съществуващата история ще остане налична.

Responsive behavior

Same intent, different temporary container.

KOKI не форсира един overlay geometry навсякъде. Intent и hierarchy са еднакви; механиката се адаптира към пространство и input method.

MenuDesktop/pointer: anchored menu. Mobile: може да остане menu само ако targets и viewport са достатъчни.Floating
PopoverDesktop: anchored popover. Mobile: promote към sheet, ако съдържанието е по-дълго или anchor positioning е нестабилно.Floating → Modal
DialogDesktop: centered dialog. Mobile: dialog за кратко critical решение; sheet за по-дълъг task.Modal
SheetMobile-first. На wide desktop същият intent обикновено става dialog/popover, не огромен bottom sheet.Modal
Accessibility & interaction contract

Temporary context must never trap the user accidentally.

Floating

FocusFocus влиза в menu/popover при keyboard invocation, ако има interactive content.
DismissEscape и outside click затварят, освен ако това би загубило незапазено critical input.
ReturnСлед close focus се връща към trigger-а.

Modal

TrapFocus остава вътре в active modal context.
BackgroundОсновният content е inert/недостъпен за interaction докато modal е отворен.
Back/EscapeУважават platform expectation, освен ако explicit confirmation е необходима за предотвратяване на загуба.
Governance

Depth is governed by behavior, not taste.

ModalDialog/Sheet с frozen Surface + modal shadow + neutral scrim.
