Buttons

Hierarchy through treatment, not decoration.

Button hierarchy is limited and explicit. Primary is reserved for the dominant action in the current task; Secondary supports it; Quiet is for low-emphasis actions; Destructive is semantic and never used as decoration.

Icon buttons

44px target. 20px glyph. Accessible name.

Icon-only controls are reserved for universally recognizable, repeated actions. Ambiguous or high-risk actions require text.

Text fields

Label, control, assistance — always in that order.

Placeholder is not a label. Error replaces generic help only when a validation problem exists. Fields remain solid surfaces with no shadow.

Search & select

Search is a field. Selection is an explicit choice.

Select displays a committed value; search/combobox behavior is added only when the dataset requires it.

Checkbox & radio

Selection controls keep the text primary.

The control is a 20px cue; the row provides the 52px interaction area and the text carries meaning.

Switch

A switch changes an immediate binary setting.

Switch is not used for submit, confirmation or navigation. The setting takes effect immediately and the label remains outside the control.

Do not useDestructive actions, multi-step business decisions, submit, save or navigation.
State contract

Every control has the same state vocabulary.

Components may render states differently, but they cannot invent their own state names or timing. Focus is always visible; disabled is not interactive; loading preserves geometry.

Governance

Controls cannot invent a parallel design system.

Allowed

ComposeFrozen colors, type, density, radii, surfaces, icons and motion.
Variant by meaningPrimary/Secondary/Quiet/Destructive or field/choice semantics.
EscalateA truly new need becomes a design-system proposal before production use.

Not allowed

Mockup copyNo old button geometry, pill treatment, chips, input chrome or toggle style survives by default.
New metricsNo ad-hoc control heights, radii or spacing.
New colorNo local accent or custom semantic tint.
Decorative motionNo bounce, glow, shimmer or component-specific timing.
