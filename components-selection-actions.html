Selection & Actions
KOKI / Components / Principles
Selection is a task mode

Browse cleanly. Select deliberately. Act with clear scope.

KOKI не показва selection controls постоянно само защото даден списък технически може да се избира. Normal browsing остава чисто. Selection mode се появява, когато потребителят започне задача по избор; action scope е винаги видим преди изпълнение.

Candidate 0.1 · built only from frozen layers
Browse

Няма checkbox chrome. Row остава Content System row и навигацията е основното действие.

Select

Cobalt маркира explicit selection. Selection controls и contextual actions се появяват като временен task mode.

Consequence

Critical се използва само за destructive действие и никога за обикновена selected state.

Core contract

Selection ≠ navigationTap за отваряне и tap за избор не трябва да са двусмислени в един и същи режим.
Scope firstБроят и обхватът на избраните обекти са видими преди bulk action.
No new chromeИзползваме frozen controls, Surface/Subtle, borders и semantic colors.

Color roles

CobaltSelected / primary action.
NeutralUnselected / browse mode.
CriticalDestructive consequence only.
Single selection

One choice should read as a choice, not as a status badge.

Single selection е подходящ за mutually exclusive options или избор на един обект за следваща стъпка. Radio geometry идва от frozen Core Controls; selected row използва Subtle + Cobalt rail.

Multi-select

Selection mode changes the task, not the visual identity.

Потребителят влиза изрично в multi-select. Тогава row anatomy резервира leading selection column за всички редове, за да няма различна геометрия между избран и неизбран item.

Bulk actions

Bulk actions must expose scope before consequence.

Contextual action area е част от selection mode, не floating overlay. Няма shadow. Тя използва border и Surface и показва броя на засегнатите обекти преди действие.

Action hierarchy

PrimaryЕдно действие може да бъде primary само ако е най-вероятният следващ task step.
SecondaryОстаналите действия използват frozen secondary/quiet controls.
DestructiveНе се издига до primary само защото е важно; остава ясно Critical.

Scope language

Count„3 избрани“, не generic „Selection“.
Object typeАко е важно за consequence, назови какво се променя: разговори, обяви, продажби.
Mixed scopeНе позволявай bulk action върху несъвместими object types само защото са в един viewport.
Destructive action

Selection is not consent to destruction.

Избирането на обекти определя scope. То не замества confirmation, когато consequence е разрушителна или трудно обратима. Confirmation използва frozen Overlay/Feedback contracts.

Async action states

Action state changes must not move the layout.

Loading, disabled и completed са states на frozen controls. Width и action placement остават стабилни. Progress се показва само когато действието реално продължава.

Disabled

Причината трябва да е разбираема от context-а; disabled не е substitute за permission explanation.

Running

Label описва текущото действие. Spinner е functional, не ambient animation.

Completed

След успех control се връща към нормално състояние; резултатът се комуникира от Feedback & Status.

3 обекта архивирани
Mobile composition

Selection mode becomes explicit at the top; actions stay reachable below.

Mobile не натъпква всички действия в app bar. Top area показва task mode и count. Двете най-важни bulk actions са в static action area над системната navigation зона; няма floating dock и няма нов shadow.

Governance

Selection is temporary state; action semantics stay permanent.

Allowed

Explicit modeВлизане/излизане от multi-select с ясно действие.
Cobalt selectedSubtle + Cobalt rail/control за explicit selected state.
Scoped actionsCount и affected object type преди bulk consequence.
Frozen feedbackSuccess/error отива във Feedback & Status, не се изобретява локално.

Not allowed

Permanent checkboxesНе показвай selection chrome в normal browse без task причина.
Selected pillsНяма badge/pill за row selection.
Floating bulk barНяма detached shadow toolbar над content-а.
Selection = confirmationИзборът на item никога не е implicit consent за destructive action.
