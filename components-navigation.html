KOKI / Components / Principles
Instagram-like navigation grammar · KOKI identity

Icon-first, persistent, almost invisible.

Навигацията не трябва да изглежда като enterprise control panel. KOKI използва Instagram-подобна структура: на mobile основните destinations са постоянни icon-only позиции долу; на desktop същите destinations стават лява sidebar с icon + label. Няма selected pills, цветни контейнери или floating dock.

State contract

Navigation state is intentionally minimal.

DefaultNeutral Ink 2 icon/text.
CurrentCobalt emphasis only; no filled container.
PressedBrief scale/neutral surface acknowledgement using frozen motion.
FocusVisible frozen focus ring for keyboard navigation.
UnavailableDo not keep dead destinations in primary navigation unless the state itself is meaningful and explained.
Governance

Instagram-like means structural simplicity, not visual copying.

Allowed

Persistent iconsStable destination order across the product.
Desktop labelsReveal labels when horizontal space allows.
Minimal selected stateUse color/text emphasis only.

Not allowed

Selected pillsNo rounded colored containers around current destination.
Floating bottom dockNo detached glass/card navigation surface.
Oversized create FABCreate stays in the same navigation rhythm as other destinations.
Instagram brandingNo copied logo, proprietary glyphs or brand styling.
