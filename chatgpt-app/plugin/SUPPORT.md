# KOKI Support

KOKI support covers the ChatGPT plugin, KOKI account connection, marketplace integrations, search, conversations, automation controls and listing workflows.

## Before reporting a problem

Please note the approximate time of the issue, the affected marketplace, the KOKI listing/search/conversation title, and the action you attempted. Do not send passwords, marketplace cookies, API keys or other authentication secrets.

## Common actions

- If ChatGPT can no longer access KOKI, disconnect and reconnect the KOKI app from ChatGPT settings.
- If a marketplace connection has expired, reconnect that marketplace from the KOKI profile.
- If an external action has uncertain status, refresh the relevant conversation, listing or search before repeating it.
- If KOKI automation should not send further messages, use **Stop KOKI** or take over the conversation.

## Privacy and account requests

For privacy, access or deletion requests, use the same KOKI support channel and clearly identify the request as a privacy request. KOKI will not ask for your password in a support request.
