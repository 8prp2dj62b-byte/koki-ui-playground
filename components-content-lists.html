KOKI / Components / Principles
Content layer · no mockup inheritance

Content has anatomy before it has decoration.

Този слой определя как KOKI подрежда read-only информация, повтарящи се обекти и дълъг текст. Не копира cards, conversation rows или dashboard blocks от старите mockups. Първо идват hierarchy, whitespace и divider; surface boundary се добавя само когато content group е реален самостоятелен обект.

Candidate · review before freeze

Core grammar

Row before cardRepeated objects live in one list surface with dividers, not in separate cards.
Text before iconTitle and metadata carry meaning. Media/icon accelerates recognition only when useful.
One trailing roleTrailing area contains one value, one disclosure cue or one compact action — never a second information column.

Reserved for later layers

StatusBadges, semantic status treatments and severity belong to Feedback & Status, not this module.
AI meaningReasoning, evidence, confidence and autonomy belong to KOKI Intelligence Components.
ActionsButtons and controls are consumed from frozen Core Controls; this layer does not redraw them.
Base list row

52px is the smallest complete content row.

The base row handles one title, optional metadata and one trailing role. It is intentionally plain so dense operational lists stay readable.

Narrative content

Long text stays readable and narrow.

Descriptions, explanations and audit text need reading rhythm rather than dashboard density. KOKI keeps narrative content around the frozen readable width.

Governance

Content components do not become a second card system.

Allowed

ComposeFrozen type, spacing, surfaces, controls, icons and navigation.
Choose anatomyBase row, media row, object summary, facts or narrative based on information structure.
Remove optional slotsMedia, metadata or trailing value disappear when they do not add meaning.

Not allowed

Card-per-itemNo default rounded container around every repeated object.
Badge inventionNo local status pills/chips before Feedback & Status is defined.
Decorative thumbnailsNo image/icon slot merely to fill empty space.
Mockup recoveryNo old dashboard cards, chat rows or listing card treatments are carried forward.
