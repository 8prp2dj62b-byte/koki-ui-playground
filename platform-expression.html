KOKI / Platform / Principles
One KOKI · three expressions

Platform adapts the shell, not the product identity.

KOKI остава една система. Platform adapter не променя Mineral Spectrum, typography, content grammar, status semantics, AI language или information architecture. Той адаптира chrome, safe areas, target size, pointer/touch behavior и responsive composition според реалната среда.

Candidate 0.1 · PWA only · no native imitation
iOS expression

44px minimum targets, safe-area aware shell и ограничена translucency само в persistent app chrome, с solid Surface fallback.

Android expression

≥48px interaction targets, solid chrome, edge-to-edge composition и по-ясна touch affordance без фалшив Material skin.

Desktop / Web

244px sidebar / 72px rail, pointer + hover + keyboard, по-широка information density и без mobile bottom navigation.

iOS PWA expression

Use iOS affordances where the web can truthfully support them.

KOKI PWA не се преструва на native iOS app. Използва safe areas, 44px touch targets, compact persistent chrome и може да използва translucency само за top/bottom app chrome. Content, dialogs, sheets and evidence surfaces остават solid Surface.

Shell

Safe top`env(safe-area-inset-top)` се добавя към persistent top chrome.
Safe bottomBottom navigation уважава `env(safe-area-inset-bottom)`.
TouchМинимум 44px hit target; frozen 20/24px icons остават визуално по-малки от target-а.
BackDetail view запазва explicit Back control; не разчитаме, че PWA има native swipe-back.

Translucency

AllowedTop/bottom persistent navigation chrome само когато подобрява depth между chrome и scrolling content.
FallbackПри липса на `backdrop-filter` chrome става frozen Surface, без визуален дефект.
ForbiddenGlass content cards, translucent dialogs, glass AI surfaces или blur като KOKI brand.
Android PWA expression

Android gets stronger touch geometry, not a Material costume.

KOKI запазва собствената си форма. Android adapter увеличава touch targets до ≥48px, държи persistent chrome solid и използва capability-driven press/hover behavior. Не копираме Material components и не променяме Mineral Spectrum.

Touch expression

TargetsIcon buttons и primary touch controls са ≥48px.
PressКратък Subtle feedback е допустим при press; без декоративен bounce или custom ripple system.
Edge to edgeContent може да използва целия viewport, но safe-area/env insets остават уважени.

Navigation

Mobile destinationsСъщите 5 frozen positions като iOS.
ChromeSolid Surface по подразбиране; няма platform glass requirement.
BackWeb history/popstate може да се използва, но UI винаги има валиден explicit navigation path.
Desktop / Web expression

Desktop spends space on orientation and information density.

Wide web не е stretched mobile. Frozen Navigation използва 244px persistent sidebar, 72px rail при по-тесен desktop/tablet режим, а content area използва pointer, keyboard и wider Scan/Inspect layouts.

Primary navigation

Wide244px sidebar с 24px icons и visible labels.
Medium72px icon-only rail със същия destination order.
SelectedCobalt icon/text, без filled selected background.

Input richness

PointerHover affordances само при `hover:hover`.
Keyboard`focus-visible` е задължителен за navigation, controls и temporary context.
Density44/52/60px frozen tiers се използват според task density; не се въвежда desktop-only micro text.

Capabilities & environment

Adapt to what the environment can do, not to a costume.

Production shell комбинира viewport, pointer/hover capabilities, safe-area env values, `prefers-color-scheme`, `prefers-reduced-motion` и `display-mode`. Platform identity може да информира shell-а, но компонентите не трябва да зависят от fragile user-agent styling.

Capability queries

@media (hover:hover) { /* pointer hover only */ } @media (pointer:coarse) { /* preserve larger touch targets */ } @media (prefers-reduced-motion:reduce) { /* remove movement, keep meaning */ } @media (display-mode:standalone) { /* installed PWA shell adjustments */ }

Environment

Safe areas`env(safe-area-inset-*)` only where chrome touches viewport edges.
ThemeFrozen light/dark tokens remain the source of truth.
OfflineOffline/loading is a Feedback/Status concern, not a platform-specific visual identity.
Governance

Platform expression is a thin adapter, never a second design system.

Allowed

Safe-area compositionTop/bottom viewport insets and installed-PWA shell behavior.
Target adaptation44px iOS/web minimum, ≥48px Android touch expression.
iOS chrome glassRestrained translucency only in persistent navigation chrome with solid fallback.
Desktop densitySidebar/rail and wider layouts using frozen type/spacing/density.

Not allowed

Native cosplayNo fake UIKit/Material controls, fake status bars or platform logos.
Platform colorsNo iOS blue / Material dynamic color replacing Mineral Spectrum.
IA driftNo platform-specific destination order or hidden core capability.
Glass contentNo blur on content, KOKI intelligence, forms or static surfaces.
